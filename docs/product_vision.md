# Product Vision

本项目的产品目标不是“上传视频并生成一个报告”，而是建立面向竞技自行车训练的 AI 数据和模型闭环。

## 用户

- 教练员：需要快速定位动作问题，比较不同趟次和不同运动员。
- 运动员：需要理解自己的动作变化和训练建议。
- 科研人员：需要可追溯的数据、模型输出、标注和评估结果。
- 项目组：需要持续积累数据集、模型能力和可交付成果。

## 产品原则

1. 结论必须可回看：每个指标和建议都能追溯到视频帧、曲线和模型置信度。
2. 精度优先于炫技：优先解决自行车场景下的关键点稳定性、遮挡、左右混淆。
3. 数据持续增值：每次使用系统都应增加数据资产或失败样本资产。
4. 模型可替换：Sapiens2、RTMPose、自研模型都必须走统一接口。
5. 科研自然生长：论文问题来自真实产品追求高精度过程中的误差分析和模型改进。
