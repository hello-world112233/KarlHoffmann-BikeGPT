## 3. Mac：BikeTrialMatcher（用户自建工具）

- **App**：`BikeTrialMatcher.app`（SwiftUI + Python CLI + AVFoundation 读 metadata，无需 Homebrew FFmpeg）。
- **源码/构建**（用户机器）：`/Users/chloe/.codex/.chatgpt-projects/g-p-6a6c442e2e0c81919a8c98f210d23ecf`
- **当前项目 DB**：`/Users/chloe/Documents/bike/cam3/project.sqlite`
- **扫描规模（约）**：A 28 有效 / B 24 / C 49；多日期混在同一 SD，**旧算法**曾全局偏移错误 → B/C 全 gap。
- **新算法**（`matching.py`）：按日期 → session（>40min 切分）→ 每 session 独立 offset → DP 对齐；缺失机位降置信度。
- **预演（仅 metadata）**：A 有效 Trial 28；配到 B 12、C 26；高分示例（5/28）如 `0015 / 0018(B) / 0032(C)` ~97 分。
- **用户须在 App 内重新点「自动配对」** 才会写入新结果；**不要未经确认覆盖** `project.sqlite`。
- **上传默认远端**：`/root/autodl-tmp/bike_projects/<project_slug>/trials/Txxx/...` + manifest。
- **主链路**：SD → Mac rsync SSH → AutoDL；阿里云盘 API 第二段不稳定，非主路径。

给 Cursor 的要求（用户原话摘要）：勿改回 Tk/浏览器；优先 manifest 里 session offset、Trial 匹配依据展示、手动改分配；勿 90GB 全解码/复制到 Mac。
