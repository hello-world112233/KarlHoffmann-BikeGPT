# Changxing 6-Day Plan

## 总目标

白天采集真实训练数据，晚上把数据接入系统，形成数据-模型-标注-评估闭环。

## Day 1

- 明确采集协议和命名规则
- 登记第一批视频
- 记录机位、场景、运动员匿名 ID 和教练备注

## Day 2

- 覆盖原地出发、行进间启动、匀速骑行
- 记录不同机位和不同遮挡条件
- 开始抽帧并检查画面质量

## Day 3

- 跑 Sapiens2/RTMPose baseline
- 输出 overlay 和失败帧
- 建立第一版 failure taxonomy

## Day 4

- 按失败类型补采数据
- 选择 200-500 张关键帧准备标注
- 明确自行车专项点

## Day 5

- 导出标注任务
- 回收或模拟第一批修正标注
- 建立 dataset v0.1

## Day 6

- 整理 baseline report
- 输出下一阶段模型改进计划
- 准备给老师/领导看的阶段汇报
