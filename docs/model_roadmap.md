# Model Roadmap

## 阶段 1：Baseline

使用 Sapiens2 和 RTMPose 作为强 baseline，输出关键点、置信度、可视化和失败样本。

## 阶段 2：失败样本挖掘

系统整理模型在自行车场景中的典型失效类型：

- 遮挡
- 左右混淆
- 脚踝漂移
- 低分辨率
- 运动模糊
- 多人干扰

## 阶段 3：专项数据集

基于 hard cases 建立第一版 bicycle-pose dataset，包含人体点、自行车专项点和出发事件标签。

## 阶段 4：模型改进

候选方向：

- 领域微调
- 自行车几何约束
- 时序平滑 / Kalman / EKF
- 多机位三角化
- 肌电、功率、心率多模态融合

## 阶段 5：科研验证

用同一批验证集比较 baseline 与改进模型，形成可写入报告和论文的指标。
