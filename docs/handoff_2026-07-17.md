## 4. 已发现的问题

1. **多识别多余的人**（failure type: `multi_person_confusion`）：用了通用 DETR 人体检测器，画面里的教练/工作人员也会被检测，没有「只跟运动员」的逻辑。
2. **不理解「人+车」整体**：Sapiens2 是通用 COCO-17 人体模型，不识别自行车骨架（中轴、曲柄、踏板、车把），也没有踏蹬圆周等物理先验。

## 5. 技术路线（已与用户讨论并确认方向可行）

用户的核心思路：**先建立「人骑车」的 3D 运动结构（受强物理约束），再拟合到 2D 视频**（2D 是 3D 的投影）。评估结论：**可行且务实，优于一上来就做 4 机位三维重建。**

关键依据：
- 骑行是强约束运动：手在车把、臀在座垫、脚在踏板绕中轴做圆周 → 自由度极低，2D→3D lifting 比通用人体好解。
- 自行车是刚体，几何已知（曲柄长、轴距），固定座场景车不动 → 提供绝对尺度与稳定车体坐标系。
- 踏蹬周期、近矢状面 → 脚踝在车体系内绕中轴画圆（半径=曲柄长），是强解析约束。
- 固定座视频背景干净、单人 → 建模与验证的最佳起点。

风险与应对：
- 单视角深度歧义：侧面对矢状面运动（髋膝踝、踏蹬）好；垂直画面的运动（上半身扭动、出发段姿态）弱 → 出发段建议加正面/斜前机位。
- 出发段上半身变化大且教练要求高 → 匀速段用强约束，出发段单独建模、弱约束、更细关键点。
- 相机与车体不垂直 → 用自行车刚体模型反求相机-车体位姿。
- 3D 先验需要数据 → 先用解析模型（曲柄运动学+肢体长度）起步。

与老师「4 机位三维重建」的关系：**不对立，是主从**。单目+约束为主力（便宜、可跑历史/比赛视频），4 机位作为金标准用于**验证/标定**单目 3D 精度（本身即论文核心实验）。
